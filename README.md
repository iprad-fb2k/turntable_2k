# Technics SL-1200MK6 Turntable Deck
Theme for [foobar2000](https://www.foobar2000.org), imitating the Technics SL-1200MK6 turntable deck

Implemented based on [foo_uie_wsh_panel_mod_plus](https://github.com/ttsping/foo_uie_wsh_panel_mod_plus) from [ttsping](https://github.com/ttsping) for any resolution, up to 2K.

Scales to fit the window.
